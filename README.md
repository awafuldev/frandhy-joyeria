# Frandhy Joyería — "La Mina de Plata 925" (Santiago, RD)

Sitio web insignia desarrollado con diseño contemporáneo de alto contraste (**Midnight Sapphire, Sterling Platinum & Diamond Ice**).
Pura arquitectura estática (HTML5 semántico, CSS3 moderno, JavaScript Vanilla puro) con persistencia reactiva en `localStorage`.

---

## 🚀 Cómo abrir y ver el proyecto

1. Abre la carpeta del proyecto:
   `c:\Users\user1\Documents\antigravity\cool-bardeen\frandhy-joyeria\`
2. Haz **doble clic en `index.html`** (o ábrelo en tu navegador favorito).
3. ¡Listo! Funciona de manera autónoma sin requerir base de datos ni servidor web.

También sincronizado con tu **Escritorio de Windows** (`C:\Users\user1\Desktop\frandhy-joyeria\`) y listo para XAMPP (`C:\xampp\htdocs\frandhy-joyeria\`).
